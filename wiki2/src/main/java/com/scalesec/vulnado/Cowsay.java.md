# Documentation: Cowsay.java

## Overview
The `Cowsay` class is designed to execute the Unix `cowsay` command, which generates ASCII art of a cow saying a given message. This class provides a method to run the command with user-provided input and returns the resulting output as a string. It is primarily intended for integration with systems that require dynamic text-based visualizations or fun outputs.

---

## Key Features
- **Command Execution**: Executes the `cowsay` command using a `ProcessBuilder`.
- **Input Sanitization**: Escapes double quotes in the input to prevent command injection vulnerabilities.
- **Error Handling**: Logs errors using Java's `Logger` in case of issues during command execution.
- **Output Retrieval**: Captures and returns the output of the `cowsay` command.

---

## Class Details

### Class: `Cowsay`
- **Purpose**: Provides functionality to execute the `cowsay` command and retrieve its output.
- **Accessibility**: The class is public, allowing it to be used across different parts of the application.

#### Constructor
- **`private Cowsay()`**: Prevents instantiation of the class, as it is designed to be used statically.

#### Method: `run(String input)`
- **Purpose**: Executes the `cowsay` command with the provided input and returns the output.
- **Parameters**:
  - `input` (String): The text to be displayed by the `cowsay` command.
- **Returns**:
  - `String`: The ASCII art generated by the `cowsay` command.
- **Logic**:
  - Constructs the command string by appending the sanitized input to the `cowsay` command.
  - Uses `ProcessBuilder` to execute the command in a Bash shell.
  - Reads the output of the command using a `BufferedReader`.
  - Handles exceptions and logs errors using `Logger`.
- **Error Handling**:
  - Logs errors at the `SEVERE` level if the command execution fails.

---

## Insights

### Security Considerations
- **Input Sanitization**: The method escapes double quotes in the input to mitigate command injection risks. However, additional sanitization may be required to handle other special characters or malicious inputs.
- **Command Execution Risks**: Direct execution of system commands can expose the application to security vulnerabilities. It is recommended to validate and restrict inputs further.

### Dependencies
- **System Dependency**: The `cowsay` command must be installed and accessible at `/usr/games/cowsay` on the host system.
- **Java Classes**:
  - `Logger`: Used for logging errors.
  - `ProcessBuilder`: Used for executing system commands.
  - `BufferedReader`: Used for reading the command output.

### Use Case
This class is suitable for applications that require dynamic ASCII art generation for user-provided text, such as chatbots, terminal-based games, or fun logging utilities.

---

## Example Usage
```java
String message = "Hello, World!";
String result = Cowsay.run(message);
System.out.println(result);
```

This example will execute the `cowsay` command with the input "Hello, World!" and print the resulting ASCII art to the console.
